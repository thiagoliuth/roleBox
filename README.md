# Proposta

As cidades têm muitos eventos, dos mais variados tipos. Festas, baladas, raves, peças teatrais, festivais culinários, palestras, e muito mais!

Assim, decidimos criar o PartyBox, um projeto para você encontrar os eventos da sua região e depois os avaliar.

Os eventos vão trazer informações como:

- nome

- data

- endereço

- se é gratuito ou pago

- link para site oficial

- link para o Instagram


# Estrutura do Projeto

### Tela de Login e Criação de Conta 🔐

Permite ao usuário criar sua própria conta e fazer autenticação, utilizando o sistema nativo de usuários do Django

### Tela de Cadastrar Eventos 📅

Um usuário pode cadastrar os seus próprios eventos (mas atenção, deve sempre fornecer nome, data e endereço!)

### Lista de eventos 🤩

Aqui, o usuário pode saber de tudo o que está acontecendo na região. Inclusive, pode filtrar por suas categorias preferidas!

### Tela de configuração de usuário ⚙️

Aqui o usuário pode alteras as suas próprias informações ou configurações gerais da aplicação.

### Tela "Meus Eventos"

Por meio dessa tela, o usuário pode ver os próprios eventos listados. Útil para organizadores!

### Tela de edição de evento

O usuário pode editar um de seus eventos cadastrados, caso ocorra mudanças nos planos, ou até mesmo excluir um evento (😥)
